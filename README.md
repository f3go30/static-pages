# static-pages (multi-app static host)

Static content published via GitHub Pages ("deploy from a branch", `main`/root) at
<https://f3go30.github.io/static-pages/>. Originally F3Go30-only; now shared by more than one app,
each namespaced under its own top-level folder.

Built output only — never hand-edited. See **[PUBLISHERS.md](PUBLISHERS.md)** for which project repo
owns which folder, the live URLs, and the ownership map the publishing pipeline validates against.
